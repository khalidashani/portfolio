# Khalid Ashani - Personal Website

A clean, minimalist personal portfolio and fitness tracking website built using HTML, CSS, and JavaScript. Hosted via GitHub Pages, it serves as a digital hub for professional contact, coding projects, and personal progress tracking.

---

## 🚀 Live Demo
You can view the live site at: [khalidashani.com](https://www.khalidashani.com)

---

## 📂 Site Structure

### 1. Home (`index.html`)
The landing page provides a brief introduction and high-level navigation to the rest of the site.

### 2. Running Progress (`running.html`)
A dedicated dashboard for tracking fitness goals and endurance milestones.
* **Feature:** Dynamic 2026 Goal Tracker (1,000km).
* **Tech:** Uses the JavaScript `fetch` API to pull live data from a Google Sheets CSV export.
* **Functionality:** Automatically calculates total distance, calculates the remaining distance to the goal, and updates a visual progress bar.

### 3. Coding Projects (`coding_project.html`)
A showcase of technical work, development experiments, and professional projects.

### 4. Contact (`contact.html`)
Provides direct channels for professional or personal inquiries.

---

## 🛠 Tech Stack
* **Frontend:** HTML5, CSS3 (Custom styling).
* **Scripting:** Vanilla JavaScript (ES6+).
* **Data Integration:** Google Sheets (via CSV publishing) for real-time data synchronization.
* **Hosting:** GitHub Pages.

---

## ⚙️ Key Features
* **Responsive Design:** Fully optimized for both desktop and mobile viewing.
* **Automated Stats:** The running tracker updates automatically whenever the linked Google Sheet is modified, eliminating the need for manual code updates.
* **Minimalist UI:** Focuses on readability and high-speed performance.
